# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Phase Classification

**Phase 1 is an infrastructure phase with no user-facing UI deliverables.** Requirements INF-01, INF-02, and INF-03 are entirely backend (LLM provider abstraction, per-role model config, env-based API keys). The success criteria involve running services, making LLM calls, and switching providers -- none require visual output.

This UI-SPEC establishes the **design system foundation** so downstream phases (Phase 5: Overlay UI Shell onward) have a consistent contract to build against. The design tokens and component library decisions made here propagate to all future phases.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, badge padding |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, panel gutters |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: 44px minimum touch target for interactive elements in the overlay (relevant from Phase 5 onward -- reps interact while on live calls and need reliable tap targets)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 500 (medium) | 1.4 |
| Heading | 18px | 600 (semibold) | 1.2 |
| Display | 24px | 600 (semibold) | 1.2 |

**Rationale:** The overlay runs on top of RingCentral in a floating panel. Compact typography (14px body, not 16px) maximizes information density in limited overlay space. The rep needs to glance at suggestions quickly -- 14px at 1.5 line-height is readable without consuming excessive vertical space.

Font family: `var(--font-geist-sans)` for all UI text. `var(--font-geist-mono)` reserved for code, timestamps, and technical identifiers only.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | zinc-950 (#09090b) | Overlay background -- dark theme for minimal screen distraction during calls |
| Secondary (30%) | zinc-900 (#18181b) | Cards, suggestion panels, transcript container |
| Accent (10%) | blue-500 (#3b82f6) | Primary CTA buttons, active flow stage indicator, current suggestion highlight |
| Destructive | red-500 (#ef4444) | End call action, max-retry warning, error states only |

**Dark theme rationale:** The overlay floats on top of RingCentral (a light-themed app). A dark overlay provides clear visual separation so the rep instantly knows which UI is the copilot vs the phone system. Dark backgrounds also reduce eye strain during long call sessions.

Accent reserved for:
- Primary action buttons (Phase 5+)
- Active flow position indicator (Phase 7)
- Current "say now" suggestion border/highlight (Phase 6)
- Connected/active call status indicator (Phase 2+)
